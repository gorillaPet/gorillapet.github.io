My WoW guild love the in game gambling addon, so I thought it could be fun for my first actual project to create an Aviator style gambling game that I could manage using a discord bot. This was the first flask app I built, and I specifically wanted to utilise OAuth, use a database to store credit balance, and I wanted it all to run using /commands in discord.

I used the probabalistic distribution function from numpy to generate a random number centered at 1.3, which seemed to be the sweet spot. Then everyone got bored of playing for fake coins, so I jacked it up to around 5-6 so we could have some huge games. Players register using /register and can login on the website using their discord account. Each player can bet during the betting window, and if they cash out before the "crash", they get their bet back multiplied by the cash out number. This is riddled with design flaws, UI bugs, and some massive security concerns (can a user invite a bot to their own server and update the centralised database? probably), but it was a really fun project and the guys seemed to enjoy it.
