embedded projects

"Medispense" was an embedded systems project for a level-200 unit that I made using a 3d printed dispenser, raspberry pi, and a servo. While it wasn't especially inspired, it was my first attempt at something using an actual GUI alongside an embedded project, rather than just terminal/serial IO. The client can set a dosage schedule using the GUI, and once the medication is due, the client can dispense the meds using either the push button, or the on screen UI. The system was also built to trigger an email webhook, so that the patient receives warning when a dosage is coming up, or if the meds are overdue. While I wouldn't want to overengineer something like this with client proximity sensors or the like, there is an obvious shortcoming in the prototype in that it is only equipped to dispense using a quick retraction of a servo motor. In practice, this doesn't allow for much precision, and would benefit from internal weight/IR measurement sensors, or a more mechanical twist style system to ensure patients can load multiple doses but only have one dispensed. check it out
