rust slot machine

When I started studying CS 2.5 years ago, it was so I could make more technically impressive ways of annoying my friends. Coding for me started out accidentally learning some python to script a visual romance novel starring my buddy Jake, and for better or for worse it snowballed to the point where I now know what Gram-Schmidt orthogonalisation is. I'm definitely a lot better at thinking about systems and flow control, so while the rust slot machine isn't pure CS, it's my magnum opus and the logical conclusion of my study. Using the inbuilt electronics system in the game Rust, I managed to design, on a live PvP server mind you, a fully functional single line slot machine with a variable pay table.

I played Rust in 2020 and loved the electronics, but anything short of a sun activated light switch was pure magic to me. Coming back this year, I realised that the game has both XOR and AND gates, as well as Rand and bitflop switches Pairing this with the custom neon signs, and the automated resource dispensers, I managed to make a system whereby you place money in the box, the system activates, waits for a button push, then begins the Rand process. With some pretty crude if else logic, I managed to create a series of more or less likely symbols with 3 of the rarer symbols paying out a higher amount. I would love to post a video, however as a thank you for enriching the server, upon completion a kindly gentleman flew over my base in a scrap metal helicopter and blew the casino up with a rocket launcher.
